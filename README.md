# OnTrack - Modern Task Management Dashboard

OnTrack is a sleek, responsive task management web application built to help users seamlessly organize tasks, set priorities, and track daily progress from pending to done.

## 🚀 Live Demo
* **Live Application:** [ontrack-dhruvank.vercel.app](https://ontrack-dhruvank.vercel.app/)

## 🛠️ Tech Stack
* **Framework:** Next.js (React)
* **Styling:** Tailwind CSS
* **Language:** TypeScript / JavaScript
* **Deployment:** Vercel

## ✨ Key Features
* **Interactive Task Board:** Create, update, and manage tasks across different priority levels.
* **Responsive Navigation:** Clean, sticky header layout designed for optimal usability.
* **Persistent State:** Client-side local storage integration to save tasks securely.
* **Audio & Visual Alerts:** Built-in task reminder system and notification banners.
